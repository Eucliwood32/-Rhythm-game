# 채보 편집기 사용법 (3단계)

Unity 안에서 채보를 만들고 고친 뒤, 게임이 읽는 JSON으로 내보내는 창입니다.

## 열기

메뉴 **Tools > 채보 편집기**

## 처음 한 번

1. **새로 만들기**를 누르고 저장 위치를 고릅니다. (예: `Assets/Charts/Stage1.asset`)
2. **곡** 칸에 오디오 파일을 끌어다 놓습니다.
3. "Load Type" 경고가 뜨면 **설정 바꾸기**를 누릅니다. 파형을 그리고 게임 싱크를 맞추는 데 필요합니다.
4. 오른쪽 **BPM · 격자**에서 첫 박과 BPM을 맞춥니다. (아래 "BPM 맞추기")

프로젝트 하나에 곡 하나와 그 곡의 채보가 들어갑니다. 다음에 창을 열면 마지막 프로젝트가 자동으로 열립니다.

## 화면

- 가운데 세로 타임라인: 위가 미래, **아래 노란 선이 판정선**(= 지금 재생 위치)입니다. 레인 뒤에 곡 파형이 보입니다.
- 격자: 굵은 선이 마디(숫자가 마디 번호), 중간 선이 박, 옅은 선이 스냅 분할입니다. 주황 선은 BPM이 바뀌는 지점입니다.
- 왼쪽 눈금: 곡 시간. 클릭하거나 끌면 그 위치로 이동합니다. 초록 막대는 구간 반복 범위입니다.
- 오른쪽 끝 미니맵: 곡 전체입니다(아래가 처음). 흰 테두리가 지금 보이는 범위, 노란 선이 재생 위치입니다. 클릭하거나 끌면 이동합니다.
- 오른쪽 패널: 선택한 노트, BPM · 격자, 재생 · 구간 반복, 테스트 플레이 · 녹화, 자동 생성, 채보 검사, 조작 도움말

노트 모양

| 종류 | 모양 |
|---|---|
| 단노트 | 레인 색 막대 (A 빨강, B 파랑) |
| 롱노트 | 막대에 `LONG`, 위로 이어지는 몸통과 끝 손잡이 |
| 연타 | 노란 막대에 `연타`, 노란 줄무늬 구간 (구간 동안 0.3초보다 쉬지 않고 두드리면 성공) |
| 문제 있는 노트 | 빨간 테두리 (채보 검사 참고) |

## BPM 맞추기

**자동:** **BPM · 격자**의 **BPM 자동 감지**를 누르면 곡을 분석해서 BPM, 첫 박, BPM이 바뀌는 곳을 찾아 줍니다. 결과를 보고 **적용**을 누르세요. 빠른 메탈 곡은 절반(또는 두 배)으로 잡힐 수 있으니 메트로놈으로 들어 보고 **×2 / ÷2**로 고친 뒤 적용합니다.

**직접:**
1. **재생 · 구간 반복**에서 **메트로놈**을 켭니다. 마디 첫 박은 높은 소리입니다.
2. BPM을 알면 위쪽 막대의 **BPM** 칸에 숫자를 바로 입력합니다(지금 재생 위치가 속한 구간의 BPM). 모르면 곡을 틀고 박자에 맞춰 **T**를 여러 번 누르고(탭 템포) **지금 구간에 적용**.
3. 곡의 첫 박이 나오는 순간에 멈추고 **첫 박 = 재생 위치**를 누릅니다. 숫자 칸에서 직접 고쳐도 됩니다.
4. 메트로놈 소리와 곡이 맞는지 들어봅니다.
5. 곡 중간에 템포가 바뀌면 그 위치에서 **여기서 BPM 변경**을 누르고 BPM 값을 고칩니다. 변경 지점마다 새 마디가 시작됩니다.

| 확대·축소 | Ctrl+휠 또는 위쪽 확대 슬라이더 |

## 테스트 플레이

만든 채보를 편집기 안에서 바로 쳐봅니다. 판정과 체력·점수는 게임과 같은 코드로 계산하고, **열려 있는 씬의 Judge·Referee 설정**(판정 범위, Miss 피해 등)을 그대로 따릅니다. 씬에 Judge가 없으면 기본값(Perfect ±40ms, Good ±80ms)을 씁니다.

1. 시작할 위치로 옮기고 **P**(또는 위쪽 **▶ 테스트**)를 누릅니다. 재생 위치 2초 전부터 곡이 나오고, 재생 위치부터 판정합니다. **Shift+P**는 처음부터입니다.
2. **A**(위 레인) / **B**(아래 레인)로 칩니다. 맞힌 노트는 사라지고, 놓친 노트는 빨갛게 남습니다. 판정선 위에 PERFECT / GOOD / MISS와 오차(ms)가 뜹니다.
3. **Space** 또는 **Esc**로 끝냅니다. 곡이 끝나도 끝납니다.
4. 패널 **테스트 플레이 · 녹화**에 결과(Perfect/Good/Miss, 점수, 최대 콤보, 정확도, 등급, 체력이 0이 된 지점)와 **평균 오차**가 나옵니다. 늘 한쪽으로 밀리면 **보정에 반영**을 누르세요. 이 입력 보정 값은 게임과 같이 씁니다.

테스트 중에는 노트 클릭음이 나지 않고(메트로놈은 남), 편집과 되돌리기가 막힙니다.

## 키 녹화

곡을 들으며 A / B를 눌러 노트를 찍습니다.

1. **R**(또는 위쪽 **● 녹화**)을 누릅니다. 재생 위치 2초 전부터 곡이 나옵니다.
2. **A** / **B**를 누르면 그 자리에 단노트가 생깁니다. **길게 누르면**(기본 0.3초 이상) 뗀 곳까지 롱노트가 됩니다.
3. **Space** 또는 **Esc**로 끝냅니다. 녹화한 노트는 **Ctrl+Z 한 번**으로 모두 취소됩니다.

"녹화한 노트를 격자에 맞추기"를 켜 두면 지금 스냅 격자에 붙습니다. 연타는 녹화로 만들 수 없으니 연타 도구(3)로 찍으세요.

## 자동 생성

곡을 분석해서 노트를 만듭니다. 결과는 초안이니 테스트 플레이로 쳐보고 다듬으세요.

**분석이 하는 일**
- 드럼 같은 타격음과 기타·보컬 같은 지속음을 나눕니다.
- 타격음을 저음(킥) / 중음(스네어) / 고음(심벌)으로 나눠 타격 지점을 찾습니다.
- BPM과 박, 마디 첫 박을 찾습니다. (BPM 자동 감지와 같은 결과)
- 소리가 크게 바뀌는 곳에서 곡을 구간(벌스, 코러스 등)으로 나누고 구간마다 세기를 매깁니다.

**설정**
- **난이도:** 노트 사이 최소 간격과 1초 안의 최대 노트 수 (쉬움 0.45초·3.5개 ~ 매우 어려움 0.10초·12개)
- **감도:** 높을수록 작은 소리도 노트가 됩니다
- **레인:** **드럼**(기본: 킥 = B, 스네어·심벌 = A) / 교대 / 음높이 / 랜덤
- **롱노트:** 타격과 함께 새로 시작해서 길게 이어지는 소리. 그 레인에 곧 다음 노트가 오면, 비어 있는 반대 레인에 롱노트를 따로 놓습니다(드럼 모드)
- **연타:** 킥(투베이스)이나 스네어가 0.18초 이내로 빽빽하게 이어지는 곳. 킥은 B, 스네어는 A
- **박자에 맞는 소리 우선:** 박 위의 소리를 남기고 박자에서 벗어난 잡음은 줄입니다. 마디 첫 박이 가장 우선
- **곡 구간에 따라 밀도 조절:** 센 구간(코러스)은 촘촘하게, 조용한 구간은 듬성하게
- **동시치기:** 박 위에서 킥과 스네어가 같이 세게 칠 때 A·B 동시 노트
- **같은 레인 최대 연속:** 빠르게 같은 레인이 이만큼 넘게 이어지면 반대 레인으로 넘기거나 뺍니다
- **격자에 맞추기:** 지금 BPM 격자에 붙입니다. **BPM 자동 감지 → 적용**을 먼저 하면 박자에 딱 맞습니다
- **범위:** 곡 전체 / 구간 반복 범위 / 재생 위치부터 끝까지. 범위 안의 기존 노트는 지우고 새로 만듭니다(만들기 전에 물어봄, Ctrl+Z로 되돌림)

처음 누를 때 곡을 분석합니다(진행 막대가 나오고, Unity는 멈추지 않습니다). 같은 곡은 두 번째부터 분석 없이 바로 만들어지니 설정을 바꿔가며 여러 번 눌러 보세요.

### 외부 분석 (더 정확하게)

프로젝트 폴더의 `Tools/chart_analyze.py`로 곡을 미리 분석해서 불러올 수 있습니다. 편집기 안의 분석보다 무겁지만, **음원 분리(demucs)**를 쓰면 드럼만 따로 뽑아서 분석하므로 기타가 꽉 찬 메탈 곡에서 킥·스네어를 훨씬 잘 잡습니다.

1. Python을 설치하고 한 번만 `pip install librosa soundfile`(음원 분리까지 쓰려면 `pip install demucs`도)을 실행합니다.
2. `python Tools/chart_analyze.py 곡파일 --demucs`를 실행하면 곡 옆에 `곡이름.analysis.json`이 생깁니다. (음원 분리는 CPU로 곡 하나에 몇 분 걸립니다. `--demucs`를 빼면 빠릅니다)
3. 그 파일을 Unity 프로젝트 안(예: `Assets/Charts`)에 넣고, **자동 생성 › 외부 분석 불러오기**로 고릅니다.
4. 이후 **자동 생성**과 **BPM 자동 감지**가 이 분석을 씁니다. **내부 분석으로**를 누르면 원래대로 돌아갑니다.

## 채보 검사

오른쪽 **채보 검사**에 문제가 목록으로 나오고, 누르면 그 노트로 이동합니다.

- ● (판정이 꼬일 수 있음): 같은 레인 같은 시각 노트 두 개, 롱노트·연타 구간 안의 노트, 길이 0인 롱노트·연타, 곡이 끝난 뒤의 노트
- ○ (주의): 같은 레인에서 0.08초보다 붙은 노트, 초당 15회 넘는 연타, 곡 끝을 넘어가는 길이

다른 레인끼리 같은 시각인 것(동시치기)은 문제가 아닙니다. ● 문제가 있으면 JSON 내보내기 때 한 번 더 물어봅니다.

## 저장과 게임 연결

- 편집 내용과 BPM은 프로젝트 파일에 바로 들어갑니다. **Ctrl+S**(Save Project)를 누르거나 창을 닫으면 디스크에 저장됩니다.
- 게임에 넣으려면 **JSON 내보내기**를 누르고, 만들어진 `.json` 파일을 `Composer`의 **Chart Json** 칸(또는 GameFlow 스테이지의 Chart 칸)에 넣습니다. JSON에는 노트만 들어가고 BPM은 들어가지 않습니다(게임은 시각만 씁니다).
- **JSON 불러오기**로 예전 채보(HTML 편집기에서 만든 것 포함)를 가져올 수 있습니다. 지금 노트를 바꾸기 전에 확인을 묻고, Ctrl+Z로 되돌릴 수 있습니다.

## 소리가 안 날 때

- 위쪽에 음소거 경고가 뜨면 **음소거 끄기**를 누르세요. (Game 창의 음소거 버튼과 같습니다.)
- 씬에 **Audio Listener**가 있어야 합니다. 보통 Main Camera에 붙어 있습니다.

## 알아둘 것

- **채보가 있는 곳은 세 군데**입니다. 편집은 **채보 프로젝트(.asset)**에서 하고, 게임에는 **JSON 내보내기**로 만든 파일을 넣습니다(Composer의 Chart Json 또는 GameFlow 스테이지의 Chart). Composer의 **Test Notes**는 JSON이 없을 때만 쓰는 시험용입니다.
- **타이밍 보정은 입력 보정 하나만** 쓰세요. 게임 중 `-` / `=` 키, 또는 이 편집기의 "입력 보정 (ms)"이고 둘은 같은 값입니다. MusicPlayer의 Offset Seconds는 노트 표시와 판정을 함께 밀어서 헷갈리므로 0으로 두세요.
- 판정 범위의 기본값은 `RhythmDefaults.cs`, 색은 `GameColors.cs` 한 곳에 있습니다. 여기만 고치면 게임과 편집기가 같이 바뀝니다.
